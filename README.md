> Analysis of a public benchmark dataset. **Not** a deployed monitoring system — nothing here should be used to decide that real water is safe to drink.

A false positive wastes a lab test; a false negative lets unsafe water through. Aqua-Seq therefore does not optimise accuracy — it fixes a recall target on the unsafe class and reports the precision achievable there. **UNSAFE is the positive class** (`unsafe = 1 - Potability`), and it is the *majority* class at 61%, so flagging every sample already yields 100% recall; precision at high recall is the scarce quantity.

## Summary

Random Forest reaches **ROC-AUC 0.693** ([0.651, 0.733]) on a test set used once. At the risk-aware threshold it catches **89% of unsafe samples** at **67% precision**, saving ~**20% of lab capacity** versus testing everything — and missing **45 of 400** unsafe samples.

| | Catches unsafe | Precision | Sends to lab |
|---|---|---|---|
| **Random Forest** (final) | 89% | 67% | 80% |
| Guideline rule (WHO/BIS/EPA) | 100% | 61% | 100% |
| Test everything (dummy) | 100% | 61% | 100% |

## Method

Stratified 80/20 split (seed 42) → all preprocessing inside `sklearn` Pipelines so imputer and scaler statistics refit per CV fold → randomised search (40 candidates) over 5-fold CV, with the imputation strategy as a tuned hyperparameter → threshold selected on cross-validated *training* predictions → **test set scored exactly once**, with bootstrap confidence intervals.

The guideline rule baseline flags a sample when any parameter breaches a limit taken from WHO GDWQ, BIS IS 10500:2012 or the US EPA NPDWR. Each limit carries its source and URL in `config.py`; `Conductivity` and `Organic_carbon` are excluded because no numeric drinking-water limit could be verified for either.

Leakage discipline is enforced by tests, not convention: `tests/test_pipeline_no_leakage.py` poisons the test set and asserts the fitted statistics do not move. Every number in this README is generated by `src/aqua_seq/report.py` from `results/metrics/`, so it cannot drift from the code.

## Reproduce

```powershell
# Windows PowerShell
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python scripts\run_all.py
```

```bash
# Linux / macOS
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/run_all.py
```

Regenerates every metric and figure from the raw CSV. Python 3.10+ (verified on 3.12.10), seed `42`, ~14 min. Quality gate: `pytest` (34 tests), `black --check src scripts tests`, `ruff check src scripts tests`.

## Layout

```
data/           raw CSV (committed, CC0) + column dictionary in data/README.md
notebooks/      01 audit & EDA · 02 baselines & modelling · 03 evaluation & explainability
src/aqua_seq/   config (verified guideline limits + sources) · data · features · models
                evaluate · explain · report
scripts/        run_all.py — the whole pipeline, deterministic
results/        metrics/ (JSON+CSV, the source of truth) · figures/ (PNG, 150 dpi)
tests/          schema & labels · leakage proofs · metrics & rule baseline
```

Interpretation, limitations and the full analysis narrative live in the notebooks; the complete generated tables are in [`results/metrics/readme_sections.md`](results/metrics/readme_sections.md).

**Data:** [Kaggle — Water Quality](https://www.kaggle.com/datasets/adityakadiwal/water-potability) by Aditya Kadiwal, `CC0: Public Domain`. Details in [`data/README.md`](data/README.md).
